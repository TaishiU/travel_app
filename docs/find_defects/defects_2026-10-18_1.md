### 1. `register()` 未キャッチ例外によるアプリ起動不能【Critical】

**箇所**: `lib/main.dart` (55行目付近)

```dart
await container.read(registerPushTokenUseCaseProvider).register();
runApp(UncontrolledProviderScope(container: container, child: const MyApp()));
```

`register()` の呼び出しチェーン全体に try-catch が存在しない。

- `RegisterPushTokenUseCase.register()` — try-catch なし
- `PushTokenRepositoryImpl.register()` — try-catch なし
- `PushTokenServiceImpl.register()` — try-catch なし（`getToken()` を await）

`FirebaseMessaging.getToken()` はネットワーク不達・FCMサービス不可・`PlatformException` など複数の条件で例外を投げる。この例外が `main()` まで伝播すると `runApp` が呼ばれず、**アプリが起動しなくなる**。

プッシュトークン登録の失敗はプッシュ通知が届かないことを意味するに留まり、アプリ起動をブロックする理由にならない。

**影響シーケンス:**
1. Android端末がネットワーク未接続 or FCMサービス一時不可の状態でアプリ起動
2. `getToken()` が `PlatformException` / `FirebaseException` を投げる
3. 例外が UseCase → Repository → UseCase → main.dart まで伝播
4. `runApp` が呼ばれず、アプリが黒画面のままフリーズ or クラッシュ

**影響**: Androidユーザー全員が影響対象。ネットワーク不安定環境（機内モード直後の起動、弱電波地域）でアプリ起動不能になる。

Critical 1件。

## 妥当性判定: 妥当

指摘通り、main.dart:64 の register() 呼び出しに try-catch が存在しない。呼び出しチェーン全段（UseCase → Repository → Service）いずれも例外をキャッチせず、PushTokenServiceImpl.register() 内の _firebaseMessaging.getToken()（service_impl.dart:49）が例外を投げると runApp に到達しない。再現条件・影響範囲ともに報告通り。

## 修正案

### 1. `register()` 未キャッチ例外によるアプリ起動不能【修正対象】

#### 欠陥再現手順（Androidエミュレータ）

1. Android エミュレータを起動
2. エミュレータの機内モードを ON にする（設定 → ネットワーク → 機内モード）
3. アプリを cold start する（`flutter run` またはエミュレータのランチャーからタップ）
4. **期待する動作**: アプリが起動してホーム画面が表示される
5. **実際の動作**: 黒画面のままフリーズ or クラッシュ

> iOSは `register()` が Android 判定で即 return するため（service_impl.dart:48）再現しない。

#### 修正方針

プッシュトークン登録の失敗はアプリ起動をブロックすべきでない。`main.dart` の呼び出し箇所に try-catch を追加し、例外をログ出力して処理を継続する。

アーキテクチャ上、例外変換（`ApiClientException` → `AppError`）は Repository 層の責務だが、本ケースは Firebase インフラ例外であり戻り値が `Future<void>`（`Result` 型を返さない設計）のため、呼び出し元での catch が最小変更で済む。

#### 修正箇所

**`lib/main.dart`**（64行目付近）

```dart
// Before
await container.read(registerPushTokenUseCaseProvider).register();

// After
try {
  await container.read(registerPushTokenUseCaseProvider).register();
} on Exception catch (error) {
  talker.warning('Push token registration failed. App continues without push token.', error);
}
```
